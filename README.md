# FL Cosmetics — финансовые отчёты

Flask-приложение для обработки финансовых данных Мексики: движение денежных средств, P&L, налоговая сводка, сверки и выгрузка отчётов в Excel.

## Локальный запуск

Требуется Python 3.11 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Открыть http://localhost:5000 и загрузить исходные файлы через интерфейс. Этот режим включает Flask debug; для серверного запуска в репозитории предусмотрен Gunicorn.

## Данные и настройки

- `uploads/` — загруженные файлы.
- `output/` — сформированные отчёты и сохранённое состояние обработки.
- `ANTHROPIC_API_KEY` — необязательная переменная окружения для AI-категоризации и подсказок. Без ключа AI-функции недоступны. Приложение читает её из окружения, `.env` автоматически не загружает.
- `PORT` — порт локального запуска, по умолчанию `5000`.

Исходные таблицы, сформированные отчёты и ключи хранятся вне Git.

`app.py` содержит веб-маршруты, `src/` — парсеры, расчёты, сверки и заполнение шаблонов, `templates/` и `static/` — интерфейс. Docker использует Python 3.11 и Gunicorn на порту 8080; команда для Railway записана в `Procfile`.
